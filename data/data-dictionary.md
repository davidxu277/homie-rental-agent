# Data Dictionary — `listings.json`

> **All data in this folder is synthetic (fake).** Addresses, project names, coordinates,
> agents and prices were generated by a script. Nothing here is a real listing. The data is
> shaped to *resemble* the Singapore rental market, not to be accurate about any real property.

`listings.json` is a JSON array of **502 listing objects** (500 unique + 2 intentional duplicates).

## MRT line codes

`NSL` North-South · `EWL` East-West · `CCL` Circle · `DTL` Downtown · `NEL` North-East ·
`TEL` Thomson-East Coast. Interchanges look like `EWL/NSL`.

## Reference date

Treat **"today" as 2026-07-28**. `availableFrom` dates cluster in Aug–Dec 2026.

## ⚠️ Intentional dirty / edge-case data (~12% of rows)

Real listing feeds are messy. About 60 rows carry exactly one of these mutations, and there
are 2 exact-duplicate rows. Handling these well is part of the assignment — **do not assume the
data is clean.**

- `monthlyRentSgd` as a string: `"3,500"`, `"S$3500"`, `"3500/mo"`, `"$3500 negotiable"`.
- `availableFrom` as free text: `"Immediate"`, `"ASAP"`, `"Now"`.
- `nearestMrt` = `null` (missing).
- `district` = `""` or `null` (missing).
- `sizeSqft` = `null` (missing).
- A `room` listing with `bedrooms` = `2` or `3` (contradiction).
- Absurd `monthlyRentSgd` from a data-entry typo (a dropped/extra zero, or `0`).
- `deposit` as a string like `"1 month"` instead of `{ "months": 1 }`.
- `area` with stray whitespace / wrong casing, e.g. `"  tampines  "`.
- Messy, mixed-language `description`.
- 2 exact duplicate listings (same content, duplicate `id`).

## ⚖️ Ethics note — `tenantPreferences.gender` and `tenantPreferences.nationality`

Some rows carry a `gender` and/or `nationality` preference. This mirrors a real (and
uncomfortable) feature of the Singapore room-rental market. **We are not endorsing
discrimination** — these fields are included so your agent has to decide how to handle sensitive
requests and preferences responsibly. How you treat `session-08` and these fields is something we
look at. There is no single right answer; we want to see that you *noticed* the issue and made a
deliberate choice.
